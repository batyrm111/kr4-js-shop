## О проекте

TechShop — адаптивный учебный интернет-магазин электроники. В этой версии добавлена интерактивность на чистом JavaScript: товары формируются из массива объектов, каталог поддерживает поиск, фильтрацию и сортировку, есть корзина, избранное и проверка формы заявки.

## JavaScript-файлы

- `data.js` — массив из 10 товаров. У каждого объекта одинаковые основные свойства: `id`, `title`, `category`, `price`, `isAvailable`. Дополнительно используются `icon`, `description` и `popular`.
- `catalog.js` — создание карточек через `createElement`, вывод через `append`, поиск по названию, фильтр по категории, сортировка и страница товара.
- `cart.js` — добавление/удаление товаров, изменение количества, расчёт общей суммы через `reduce`, сохранение корзины и избранного в `localStorage`.
- `validation.js` — проверка имени, e-mail и телефона, вывод ошибок и результата на страницу.
- `main.js` — общая инициализация, переключение светлой/тёмной темы и обновление счётчика корзины.

## Реализованные функции

### Обязательная часть

1. Массив из 10 товаров с единой структурой и числовыми ценами.
2. Генерация карточек товаров средствами JavaScript.
3. Поиск по названию через событие `input`.
4. Фильтрация по категории через событие `change`.
5. Сортировка по возрастанию/убыванию цены и по названию. Сортировка выполняется для копии массива.
6. Отображение количества найденных товаров и пустого состояния.
7. Валидация имени, e-mail и телефона на странице `order.html`.
8. Сообщения об ошибках и успешной подготовке заявки выводятся в DOM, без `alert()`.
9. Для текста используется `textContent`; пользовательские данные не вставляются через `innerHTML`.
10. Обработчики событий подключены через `addEventListener()`.

### Самостоятельные доработки

- Корзина: добавление, удаление и изменение количества товаров.
- Расчёт суммы корзины методом `reduce()`.
- Сохранение корзины в `localStorage` после перезагрузки страницы.
- Избранное с сохранением выбранных товаров в `localStorage`.
- Переключение светлой и тёмной темы с сохранением выбора.
- Счётчик товаров в корзине.
- Страница подробной информации о товаре.
- Имитация успешной отправки формы с очисткой полей.
- Расширенное пустое состояние каталога и кнопка сброса фильтров.

## Безопасность

Карточки и сообщения создаются через DOM-методы `createElement`, `textContent`, `classList` и `append`. Данные из полей формы не вставляются как HTML. В проекте не используется `innerHTML` для пользовательских или товарных данных.

## Как запустить

1. Скачайте или клонируйте репозиторий.
2. Откройте папку проекта в VS Code.
3. Откройте `index.html` в браузере. Для удобной разработки можно использовать расширение **Live Server** в VS Code.
4. Перейдите в каталог и проверьте поиск, фильтры, сортировку, избранное и корзину.
5. На странице оформления заказа проверьте пустую форму, неправильный e-mail/телефон и корректно заполненную форму.

Проект не требует `npm install`, сборщика или отдельного сервера: используется чистый HTML, CSS и JavaScript.

## Что проверить перед сдачей

- Открыть `index.html`, `catalog.html`, `product.html`, `cart.html`, `order.html` и `contacts.html`.
- В DevTools → Console убедиться, что нет критических ошибок.
- Проверить поиск по части названия, все категории и варианты сортировки.
- Добавить несколько товаров, обновить страницу и проверить сохранение корзины.
- Изменить количество и удалить товар.
- Проверить форму с ошибочными и корректными данными.
- Проверить отображение на узком экране.
